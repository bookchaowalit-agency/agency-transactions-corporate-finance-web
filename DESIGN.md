# Transactions & Corporate Finance — Deal room evidence board

## Visual authority

เว็บนี้เป็น public showcase แบบ static สำหรับ Transactions & Corporate Finance และใช้ visual world เฉพาะของ vertical นี้: midnight board / ledger green / deal markers

## First viewport

หน้าแรกเริ่มด้วย promise ที่อธิบายการตัดสินใจที่ช่วยได้ ต่อด้วย thesis, working artifact, buyer/offer/status signal และ CTA ไปยัง scope ที่มีจริง

## Signature artifact

Diligence begins where the evidence boundary is explicit.

Artifact ใช้ geometry ที่อธิบายภาษาของ vertical นี้และทำหน้าที่เป็น evidence loom: buyer → problem → offer → readiness

## Boundaries

สถานะ commercial คือ target / P2; URL นี้เป็น showcase เท่านั้น ไม่ใช่หลักฐานว่ามีลูกค้า agency, ไม่รับข้อมูลลูกค้า, ไม่ใช่คำแนะนำ regulated และไม่เปลี่ยนงาน freelance/client เดิมให้เป็น agency traction

## Quality floor

รักษา Thai glyphs ด้วย Noto Sans Thai/Noto Serif Thai, visible focus, skip link, 390px responsive layout, reduced-motion behavior และ contrast ที่อ่านได้จริง ห้ามเติม client claims, testimonials, pricing, credentials, lead form หรือ backend โดยไม่มี approval และ evidence
